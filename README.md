# Aleksei Bukhalov — SDET

Aleksei Bukhalov is a Software Development Engineer in Test (SDET) working across Kotlin, Python, TypeScript, and database internals. He is the author of research-mcp-server, a multi-tool MCP server providing 25 research tools for AI agents.

## Projects

- **[research-mcp-server](https://github.com/liqlos/research-mcp-server)** — 25 research tools for AI agents in one MCP server. Web search, content extraction, Reddit, YouTube, academic papers, citation verification, SEC filings. Works with Claude, Cursor, ChatGPT.
- **[findataapi](https://github.com/liqlos/findataapi)** — Financial data API with 65 endpoints, Python and JavaScript SDKs, API key management, rate limiting. 587 tests.
- **[fact_checker](https://github.com/liqlos/fact_checker)** — Chrome extension for real-time fact-checking of images and text. FastAPI backend, Google Vision, TinEye, GDELT, LLM verdict synthesis.
- **[call-analyzer](https://github.com/liqlos/call-analyzer)** — Self-hostable speech analytics platform. Whisper STT, pyannote diarization, FAISS semantic search, Next.js 15 frontend.
- **[serbian-dub](https://github.com/liqlos/serbian-dub)** — Russian-to-Serbian AI dubbing pipeline. ElevenLabs IVC voice cloning, Opus translation, MediaPipe lipsync, LUFS broadcast mix.
- **[venice-web-proxy](https://github.com/liqlos/venice-web-proxy)** — OpenAI-compatible API proxy for Venice AI. Streaming, model fallback, rate limiting. TypeScript/Bun.
- **[jetbrains-kubectl-e2e-tests](https://github.com/liqlos/jetbrains-kubectl-e2e-tests)** — End-to-end test suite for kubectl in Kotlin with Kotest. kind cluster, GitLab CI.
- **[test-task-idea-plugin](https://github.com/liqlos/test-task-idea-plugin)** — IntelliJ IDEA plugin in Kotlin. PluginManagerCore, DaemonCodeAnalyzerImpl, line markers.
